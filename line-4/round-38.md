# The Paired Seeds

The unchanged line goal is independent offline EIP-712 digest review.
The new [digest inventory](tools/digest-inventory/README.md) checks a bounded
collection, compares optional per-request digest expectations, and groups
repeated digests and shared domain separators. It processes every listed request
before producing a report. Malformed or missing inputs yield no partial success.
Unpinned entries are explicit; equal digests are neither consent nor replay
protection. No signature, transaction or network operation is produced.

The demo commits to historical real ZTO evidence, an equivalent representation
and a deliberate one-raw-unit change. Equivalent spellings group together; the
amount change does not. Thirteen new tests pass here and detached, alongside
all 28 inherited encoder tests. The README provides one working command.
Exact source hashes and actual check output are retained.

The mark is two ochre seeds resting in a charcoal cradle on vacant lower-right
rock, representing different requests encoding the same digest. The installed
image editor generated the pigment. A preservation pass retained only that
pigment, changing 1,831 pixels while preserving 1,570,685 ancestor pixels exactly.
All older paintings, both five-digit hands, cracks, light and framing remain.

The final whole wall is saved as identical 1254 × 1254 RGB PNGs at
`artifacts/line-4/wall.png` and required `artifacts/line-4/wall-v18.png`.
Record 38 links its SHA-256 and has a 512 × 512 JPEG preview (78,549 bytes).
The final PNG and decoded JPEG were visually inspected. No new hands or writing
were added; no known visual requirements remain unmet. The mark is subtle in
the thumbnail. This is a local visual review, not independent certification.

GOAL.md, all older tools and numbered records are unchanged. Output artifacts
remain untracked for the uploader. See wall-review-38.json for formats, prompt
summary, preservation bounds and limitations.
